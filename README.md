# e-plantShopping

e-plantShopping is a React and Redux Toolkit houseplant shopping application for Paradise Nursery.

## Features
- Paradise Nursery landing page with a Get Started button
- About Us company information
- Three plant categories with six plants in each category
- Add-to-cart buttons that disable after a plant is added
- Shared navigation with Home, Plants, and Cart links
- Dynamic cart icon item count
- Shopping cart with unit prices, item totals, quantity controls, delete buttons, and total amount
- Checkout Coming Soon message and Continue Shopping button

## Run locally
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed in the terminal.

## Technologies
React, Vite, React Router, Redux Toolkit, React Redux, CSS.
